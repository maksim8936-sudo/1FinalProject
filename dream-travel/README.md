# Dream Travel

Лендинг туристичної агенції Dream Travel. Це одна сторінка на HTML, CSS і JavaScript, без фреймворків.

## Що є на сторінці

- Головний екран з посадковим талоном, який змінюється під обраний напрямок
- Вісім напрямків з SVG-ілюстраціями та фільтрами за типом відпочинку, місяцем і бюджетом
- Блок «Як це працює» з чотирма кроками
- Календар сезонів: коли куди краще їхати
- Форма заявки з перевіркою полів (демо, дані нікуди не надсилаються)
- Адаптивна верстка для телефона, світла й темна тема

## Як запустити

Відкрийте `index.html` у браузері. Нічого встановлювати не потрібно.

## Технології

HTML5, CSS (custom properties, grid, flexbox), ванільний JavaScript, Google Fonts (Unbounded, Manrope, IBM Plex Mono).
