# PhotoApp

Навчальний адаптивний фотопроєкт, створений за допомогою HTML, CSS та JavaScript.

## Структура проєкту

- `index.html` — розмітка сторінки та JavaScript;
- `css/style.css` — стилі сайту;
- `assets/` — фотографії, які використовуються на сторінці.

## Запуск

Відкрийте файл `index.html` у браузері або запустіть проєкт через розширення Live Server у Visual Studio Code.
